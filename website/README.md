# LearnLoop Marketing & Documentation Web Portal

The official product website and interactive documentation portal for LearnLoop.

Built with **Next.js 16**, **React 19**, and **TailwindCSS v4**.

---

## 🚀 Quick Start

From this `website/` directory:

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🌟 Key Features Showcased

1. **Dual-Mode Execution Breakdown (`ExecutionModes.tsx`)**:
   - **Autonomous AI Pairing Hygiene (~80% of calls)**: Silent background tracking via `track_intent` (`start_session`, `log_decision`, `reconcile`).
   - **Developer-Initiated Interactive Sparring**: Triggered on-demand via natural chat or slash commands (`/review`, `/interview`, `/tour`, `/catch-up`).
2. **Interactive 4-Cluster Tool Matrix**:
   - `track_intent`: Active coding declarations & Git verification.
   - `manage_reviews`: Spaced repetition & SM-2 recall cards.
   - `manage_knowledge`: Component indexing & stale invariant alerts.
   - `explore_project`: Cognitive band tours & codebase onboarding.
3. **Interactive IDE Sparring & Terminal Simulation**:
   - Live simulated chats illustrating Socratic review dialogues and code drift detection.
4. **Zero-Workspace-Pollution & Privacy Guarantees**:
   - Explains Ghost Mode storage isolation and 100% local-first data architecture.
